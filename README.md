# Real-Time Gesture Controlled Holographic Research Interface

## Overview
A "Iron Man" style web application for visualizing and interacting with 3D molecular structures using real-time hand gestures. Built with Three.js and MediaPipe.

## Features (Phase 1)
- **Real-Time Hand Tracking**: Detects hand landmarks via webcam.
- **Gesture Control**: Pinch to grab, move, and interact.
- **Holographic Visuals**: Glowing 3D environment.
- **Mobile Support**: Works on phones and laptops.
- **PWA**: Installable as a native-like app.

## Tech Stack
- **Framework**: Vite (Vanilla JS)
- **3D Engine**: Three.js
- **Computer Vision**: MediaPipe Tasks Vision
- **Styling**: CSS3 (Responsive)

## Setup
1. `npm install`
2. `npm run dev`
3. Open `http://localhost:5173` (or network URL for mobile)
